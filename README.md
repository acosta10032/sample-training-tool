# Sample Staff Training Quiz

This is a tiny demo repository, built to show Miguel what a GitHub repository
actually looks like on the inside.

## What's in here

- `index.html` — a single-file training quiz (same style as the Carmine's
  and Alicart T3 tools), with a few sample questions about a fictional menu.
- This README — every repo usually has one, explaining what the project is
  and how to use it.

## Why this matters

Every change to `index.html` in this repo was saved as its own "commit" —
a snapshot with a timestamp and a note about what changed. Run `git log`
in this folder (or look at the commit history once it's pushed to
github.com) to see:

1. Initial quiz created (3 questions)
2. Added a 4th question about allergens
3. Improved styling and added a score summary

Nothing was overwritten — every one of those versions still exists and can
be restored at any time.

## Turning this into a real GitHub repository

1. Go to https://github.com/new
2. Name it something like `sample-training-tool`
3. Leave "Add a README" unchecked (this folder already has one)
4. Follow the "…or push an existing repository from the command line"
   instructions GitHub shows you — it's 3 commands, copy-pasted from
   that page.
5. Once pushed, turn on GitHub Pages (Settings → Pages → deploy from
   main branch) to get a real link staff can open in a browser.
